# Сохранить проект и продолжить в Codex

Единый исходный архив содержит полный отслеживаемый Repository, готовый Xcode-
проект, текущую ветку Git с историей, инструкции и контрольные суммы всех файлов.
Кэши зависимостей скачиваются при сборке. Рабочая БД, серверные нашиды, secrets,
Telegram sessions и ключи подписи хранятся отдельно и сюда не включаются.

## Сформировать архив

Экспорт и проверка POSIX-режимов файлов предназначены для Linux/macOS/Codex.
Windows поддерживает просмотр архива и сборку Android через gradlew.bat.

Сначала проверить и commit-нуть изменения. Экспорт откажется от грязного дерева,
чтобы в снимок не попали забытые исходники или частичная версия.

```sh
python3 scripts/export_project.py --output /path/Muwa-Project.zip
```

Дополнительные материалы передаются опциями `--handoff`, `--verification`,
`--references`; описание — `python3 scripts/export_project.py --help`.

После экспорта проверить целостность и реальное offline-восстановление:

```sh
python3 scripts/verify_project_archive.py /path/Muwa-Project.zip
```

Проверка включает CRC и безопасные пути ZIP, SHA-256 всех файлов, восстановление
Git из bundle без GitHub, соответствие Repository исходному commit, повторную
генерацию iOS и однократную Xcode-регистрацию. Зависимости npm/Gradle и Xcode-
компиляция проверяются отдельно — контрольная сумма не доказывает runtime-поведение.

## На телефоне

Сохраните весь ZIP в «Файлы». В новом чате Codex загрузите его и напишите:

> Это проект Muwa. Распакуй архив, прочитай Repository/AGENTS.md,
> docs/CURRENT_STATE.md и Handoff/RESTORE.md. Работай с каноническим Repository,
> сохрани утверждённую навигацию и существующие API/ключи данных.

Для восстановления Git из корня извлечённого архива:

```sh
git clone --branch feat/muwa-native-build35 History/muwa.bundle ../Muwa-work
```

Используйте одну рабочую копию: Repository или восстановленный Muwa-work.
iOS-папка служит удобным готовым проектом; правки делайте в native-patches и
пересобирайте `scripts/assemble_ios.py` в новую/пустую папку. Для push заново
подключите GitHub в новой среде, для серверного доступа — соответствующий connector.
Приватные credentials не должны попадать в ZIP или сообщения чата.
