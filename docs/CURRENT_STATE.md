# Muwa: текущее состояние — 15 октября 2026

Приложение **Muwa**, app ID **app.muwa.nasheeds**, версия **1.4.0**, iOS Build **54**, Android Build **55**.
Структурирование и переносимый архив Build53 завершены и проверены offline.
Текущий этап — приведение Android к текущему iOS Build54. Новые варианты рамок
остаются невыбранными; Android повторяет существующий дизайн iOS.
Утверждённый дизайн, геометрия навигации, API и ключи пользовательских данных
сохранены. Точный исходный commit смотреть в Git или manifest portable-архива;
одинаковый build number не означает одинаковый commit.

## Android Build55

Четыре вкладки и единый нижний бар видны и в раскрытом плеере. Сохранены
62dp высоты, 58dp мини-плеера и 8dp промежутка; прежний physical-bottom anchor
не изменён. Обложка учитывает измеренную высоту кнопок; короткий горизонтальный
экран использует компактные контролы. Фон, панели, иконки и line heights
сопоставлены с iOS; фон обложки остаётся приглушённым.

Главная, библиотека, профиль, очередь, полный текст, поиск, Premium, вход,
регистрация и пустые разделы используют ту же структуру. Есть подбор нашидов
из каталога и переименование плей-листа, подтверждение пароля при регистрации,
карточка сохранённой позиции и возврат из reader на исходную вкладку.
Поиск, вход и вложенные страницы возвращаются по одной сохраняемой истории
MuwaNavigation на свой исходный экран. Ввод пароля не сохраняется в Bundle. Все данные остаются у прежних владельцев:
MuwaModel / Library / Media3; Backend, Downloads и PlaybackService не заменялись.
Apple API не эмулируются: Android использует системный аудиовыход, шрифты,
разрешения, шаринг и биллинг своей платформы. Код iOS не изменён.

Проверки и границы: [ANDROID_IOS_PARITY_BUILD55.md](ANDROID_IOS_PARITY_BUILD55.md).
Точные CI run / source commit / результаты находятся в delivery Verification;
успешную компиляцию нельзя выдавать за физический тест или акустическую проверку ASR.

Владелец выбрал чистую Beget-базу; старые Floot-аккаунты/Premium/медиа не нужны.

развёртывания и сохранённые API-контракты уже реализованы.

В Telegram владелец пересылает файлы своему боту для каталога; исходный канал
`https://t.me/muwa144`. Права owner-only проверяются сервером. Секреты и bot sessions
не извлекаются в исходный архив. Не повторять fresh-database initializer на
работающей базе. [Деплой](BEGET-BETA-DEPLOYMENT.md) описывает первоначальную установку
и её исторические проверки, а не текущее состояние каждой строки.

## Субтитры

Whisper large-v3, CPU int8, beam 5, локальная очередь PostgreSQL. Все новые загрузки
ставятся в распознавание; импорт/публикация аудио не ждут результата. **Любой ASR
остаётся приватным черновиком до проверки и явного сохранения владельцем**.
Платные AI-провайдеры отключены. Стандартный оригинал арабских нашидов — арабский;
региональные dialect tags направляются в модель, но равная точность всех диалектов
не доказана. Пение, хор и реверберация требуют сравнения с проверенным текстом.
Не обещать максимум точности без такого сравнения.

Пять прежних auto-published текстов убраны из выдачи с приватной резервной копией;
аудио и документы распознавания сохранены. Reader появляется для доступного текста;
пустой серверный ответ убирает старый cache, reader закрывается при смене track/audio/
caption revision. При конфликте word timings с оригиналом показывается полный
оригинальный текст. iOS18+ применяет TextRenderer, iOS17 сохраняет совместимый
полный текст и движение по фразам. Reduce Motion/low power учитываются.

задача, исходный ZIP не заменяет резервную копию PostgreSQL и медиа.

Интенсивность существующего фона уменьшена: ambient lights до55% прежней силы;
iOS-фон обложки теряет усиление насыщенности и получает opacity0.34. Сами обложки,

улучшить проверку текста в панели, добавить настоящий рейтинг по прослушиваниям,
проверить внешнюю резервную копию/восстановление и измерить нагрузку сервера.

дизайнерских репозитория — источники рекомендаций, не выбранный редизайн. Новые
мокапы пока не применять. Контекст и материалы portable-архива находятся в Handoff
и DesignReferences; референсы сохраняют свои лицензии отдельно от кода Muwa.
