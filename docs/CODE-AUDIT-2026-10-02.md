# Аудит кода Muwa — 2 октября 2026

Проверена рабочая ветка `feat/muwa-native-build35`, приложение 1.4.0, build 37.
Правило дальнейшей разработки записано в [AGENTS.md](../AGENTS.md): изменять
существующую реализацию и её вызовы, удалять заменённые части; не создавать
второй обработчик, класс или источник состояния поверх первого.

## Область проверки

Проверены исходники приложения iOS, Android, CarPlay, находящиеся в репозитории
backend endpoints, миграции, подготовка Xcode-проекта, проверки и CI.
iOS проверялся как собранный проект: неизменяемый базовый архив плюс замены
из `native-patches/`. Эти замены не являются вторыми компилируемыми версиями.
Проверка подготовки запускается дважды и подтверждает единственную регистрацию
исходников, сохранение телефонной сцены и отдельной сцены CarPlay.

В эффективном iOS-проекте после удаления старой панели — 43 Swift-файла;
в Android — 11 Kotlin-файлов приложения. Поиск одинаковых исходников и
повторных объявлений типов не выявил дублирующих реализаций. Одинаковые имена
на разных платформах, тестовые адаптеры, миграции старых данных и отключённые
по решению владельца Premium/AI-флаги не считались мёртвым кодом.

Это аудит кода и проверяемых сценариев, а не доказательство отсутствия всех
возможных ошибок. Внешние зависимости и полный production-код Floot,
который не хранится в этом репозитории, не прошли отдельный полный аудит.

## Подтверждённые проблемы и исправления

| Область | Проблема | Изменение существующего кода |
| --- | --- | --- |
| Бесплатные субтитры iOS | Новый rail не запускал загрузку; загрузчик вызывала старая, уже не используемая панель | Загрузка привязана к ID трека в текущем rail; обычные субтитры видны при ожидании AI; учтён Reduce Motion |
| Авторизация iOS | Поздний ответ восстановления мог вернуть предыдущий аккаунт после входа или выбора гостя | Однократное восстановление, revision проверки ответов; выход немедленно очищает состояние и локальные session cookies даже без сети |
| Авторизация Android | Восстановление сессии конкурировало с новым входом; ошибка Premium могла выглядеть как ошибка успешного входа | Предыдущая задача отменяется, ответы проверяются по revision; сбой Premium не отменяет успешный вход |
| Очередь iOS | Намеренно пустая очередь подменялась всем каталогом при переходе и prefetch | Используется сохранённая очередь; пустая очередь завершает воспроизведение, лишний prefetch отменяется |
| «Играть следующим» | Добавление текущего трека могло переставить очередь | Текущий трек сохраняет позицию; настоящий следующий перемещается без дубликатов |
| Офлайн iOS | `localURL` мог выдавать путь отсутствующего файла | Возвращается только существующий скачанный файл; отмена не вызывает ложный alert |
| Сеть Android | Блокирующий `execute()` не был связан с отменой coroutine | Общий существующий сетевой слой использует отменяемый OkHttp callback; отмена закрывает запрос и при чтении тела; response закрывается до завершения continuation |
| Загрузки Android | Старые progress callbacks могли обновить новую загрузку того же трека | Проверяется владелец job; отмена удаляет частичный файл |
| Субтитры Android | Ответ предыдущей задачи мог перезаписать текст/индикатор нового трека | Проверка revision перед обновлением состояния |
| Таймер Android | «После текущего» мог пропустить конец при repeat или остановить уже следующий трек | Используется `pauseAtEndOfMediaItems` ExoPlayer; при отмене флаг снимается |
| Обложки Android | Жест мог помнить устаревшего соседа; показанная обложка и реально включённый трек могли различаться | Актуальный сосед читается через `rememberUpdatedState`; включается показанный трек; состояние жеста сбрасывается в `finally` |
| Читаемость Android | Полноэкранный диалог плеера наследовал чёрный цвет текста и иконок на тёмном фоне | В существующем диалоге задан foreground из `onSurface` текущей темы; проблема обнаружена по реальному screenshot эмулятора |
| Безопасные отступы Android | На небольшом телефоне нижние элементы диалога пересекались с системной навигацией | Safe Drawing insets считываются из окна Activity перед входом в отдельное окно Dialog |
| Публикация Android | Отмена coroutine могла прервать удаление временных файлов | Очистка выполняется в `NonCancellable + Dispatchers.IO` |
| CarPlay | Disconnect использовал неверную метку параметра и не был системным callback; изоляция UI-обработчиков не была согласована с протоколами SDK | Использована точная сигнатура Apple `didDisconnectInterfaceController`; синхронные входы SDK переводятся в MainActor, очистка подписок сохраняется в существующем обработчике |
| Premium backend | Проверка лимита создания кодов выполнялась вне транзакции и пропускала параллельные запросы | Короткая транзакция с блокировкой строки аккаунта: проверка лимита и создание атомарны |
| Индексы Premium | Поиск созданных кодов и активаций аккаунта не имел соответствующих индексов | Добавлены идемпотентные индексы; проверены на временной PostgreSQL |
| AI документы | `null` элементы ответа провайдера могли сорвать нормализацию; NaN нарушал сортировку; ровно 600 сегментов ошибочно отклонялись | Некорректные элементы фильтруются до сортировки; граница согласована с native validator |

Из сборки удалён неиспользуемый `SubtitlePanel.swift`. Удалены невызываемые
playlist helpers/callbacks, параметры геометрии и selection binding полноэкранного
плеера, неиспользуемая subtitle URL property, лишний Compose scope и удержание
Context в Library. Действующая нижняя навигация, меню именованных плейлистов,
совместимость сохранений и миграции сохранены.

## Проверки

- iOS: Release arm64 для устройства, Debug для симулятора, упаковка unsigned IPA
  и полного source archive. Проверки очереди/миграций, 11 вариантов геометрии,
  PlaybackTimeline, AI/legacy документов, Premium account races/expiry, launch,
  новых auth races/offline logout и офлайн-файлов.
- Android: `assembleDebug`, `assembleRelease`, `testDebugUnitTest`, `lintDebug`.
  Четыре unit-теста проходят, включая реальный MockWebServer и отмену во время
  чтения response body. Lint не сообщает ошибок; предупреждения не скрывались
  общим отключением проверок. Остаются 14 предупреждений: 10 о версиях зависимостей,
  экспортированный MediaSession service, backup/data extraction rules и два
  замечания об иконках. Экспортированный сервис используется системным медиаплеером;
  эти предупреждения не являются доказательством поломки, но требуют отдельной
  проверки конфигурации перед магазинной публикацией.
- Backend: 20 тестов проходят на отдельной временной PostgreSQL 16. Проверены
  60 одновременных созданий при лимите 50, конкурентная последняя активация,
  повторная активация без продления, disable без отзыва доступа, лимит неверных
  попыток, постоянный доступ, запрет гостю/неадминистратору/чужому Origin.
  HTTP session/schema интеграция Floot подменяется только в тестовом дереве;
  это не end-to-end проверка production authentication.
- CI дополнительно запускает захват экранов iPhone/iPad и Android, видео запуска
  и попытку подключения настоящего CarPlay external display. Недоступный CarPlay
  записывается как ограничение, без подмены макетом.

## Что ещё требует завершения

1. **Каталог зашит в клиенты и содержит семь треков.** Он согласован между
   платформами, но новые публикации из базы автоматически не появляются.
   Нужны существующий серверный feed каталога и его подключение в оба клиента.
2. **AI generation приостановлен.** Исправления валидаторов не включают оплаченного
   провайдера и не подтверждают качество распознавания нашидов. Нужен доступный
   ASR worker/provider и реальная проверка загрузка → распознавание → модерация.
3. **Публикации:** проверенный протокол загрузки файлов и финального
   `submission.json` не заменяет серверную модерацию/статусы. iOS восстановление
   черновика сохраняет метаданные, но не обеспечивает восстановление доступа к
   выбранным файлам после перезапуска; нужен корректный bookmark/копия файла.
4. **Оплата:** production StoreKit и Google Play Billing требуют конфигурации
   магазинов. Premium ограничения намеренно отключены на этапе проверки функций.
5. **Ошибки:** локальная диагностика реализована; централизованный сервис сбора
   ошибок не подключён. Нельзя считать локальный журнал удалённым мониторингом.
6. **CarPlay:** компиляция и конфигурация не подтверждают установку на автомобиль.
   Нужны одобренный Apple entitlement/profile и физическая проверка.
7. **Production backend:** новые индексы/изменения сервиса проверены на тестовой БД,
   но не развёрнуты в действующем Floot. Пользовательские данные не изменялись.
8. **Реальные устройства:** плавность жестов/120 Hz, Bluetooth, прерывания звонками,
   смена маршрута и слабая мобильная сеть требуют отдельной проверки на устройствах.

Новые сервисы или оплаченные ресурсы не подключались. Временная тестовая база
используется только для проверки транзакций и удаляется после проверки.
