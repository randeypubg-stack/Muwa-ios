# Muwa build40: фон, Главная и очередь

Исходные экраны получены заново из CI build39, commit
`29d05de86652076d19f81ac0a95084f01920c666`: iOS run `37048834249`, Android
run `37048834161`; обе сборки и исходная проверка секретов успешны.
Снимки сняты нативными Simulator/Emulator, без браузерной подмены приложения.

## Исходная проверка

1. iPhone, Главная: реальные подборки открываются, но три большие одинаковые
   строки занимают почти весь первый экран; свет в фоне визуально отсутствует.
2. iPhone, очередь: отдельные удаление/drag доступны, но заголовок выглядит
   тяжёлым, активная строка определяется жёлтой иконкой, размеры удаления малы.
3. Android, Главная: первый экран состоит из повторяющихся строк; подборки
   находятся ниже полного списка, оформление не совпадает с iOS.
4. Android, очередь: после каждого трека повторяются три текстовые кнопки,
   которые занимают много места и визуально конкурируют с названием нашида.

Снимки сохранены в `/workspace/artifacts/Muwa-design-review/before` вместе с
исходными артефактами. Они показывают визуальный результат; работа экранного
диктора и физика свайпа требуют отдельной проверки на устройстве.

## Реализация

- Общая серебристо-синяя палитра, семантические системные шрифты и размеры.
- Три мягких радиальных световых пятна с медленным движением. Фон не использует
  playback clock и большой live blur; анимация останавливается вне активной
  сцены, при ограничении движения и энергосбережении.
- Подборки по длительности имеют настоящие обложки, число треков и переход
  к соответствующему каталогу. При крупных шрифтах карточки переходят в колонку.
  Первый просмотр iPhone выявил неверное измерение ideal size в ViewThatFits:
  обычный текст тоже включал колонку. Выбор двух колонок теперь зависит от
  реальной ширины контента; текст переносится внутри карточки.
- «Откройте для себя» ограничен двенадцатью треками; полный каталог остаётся
  в «Все». iOS использует ленивую горизонтальную загрузку.
- Очередь показывает активное состояние, компактные кнопки, длительность,
  плавное удаление/перестановку и способы изменения порядка для доступности.
- При выделении файлов сохраняются существующие владельцы данных и жестов
  плеера. Архитектура описана в `docs/ARCHITECTURE.md`.

## Проверка и ограничения

Новые экраны и сборки build40 проверяются после публикации исходников в GitHub.
Окончательные результаты CI и принятые скриншоты записываются после проверки.
Изменения защиты сервера build39 пока не размещены: Floot блокирует developer
actions до заявленного сброса 3 октября 2026, 00:00 UTC. Этот UI-релиз не является
подтверждением внедрения SQL, серверных лимитов или отзыва временной QA-роли.
